# ziin.ai — Product Requirements Document

## 1. 비전
주식 투자 분석을 다루는 1인 전문 블로그.
포털과의 차별점: AI 보조로 작성하되, 모든 추천의 결과와
근거를 숨기지 않고 추적 가능하게 공개한다.

## 2. 핵심 가치 (3 Pillars)

### Pillar A: 신뢰성 (Credibility)
모든 주장은 출처에 매여 있다. 출처는 신뢰도 등급(T1~T4)으로
분류되고, 반박 근거를 의도적으로 같은 비중으로 노출한다.

### Pillar B: 연관성 (Connectivity)
모든 글, 종목, 테마, 이벤트는 지식 그래프의 노드다.
사용자는 그래프 탐색으로 의외의 연결을 발견한다.

### Pillar C: 책임성 (Accountability)
모든 추천은 검증 가능한 가설로 등록된다. 틀린 가설을
숨기지 않고, 의견 변화를 시계열로 추적한다.

### Pillar D: 지인 (Conversational Grounding)
"내 곁에 지인" 브랜드의 의인화. 대화형 에이전트는 범용 AI가
아니라 ziin.ai 분석글·타임라인·신뢰도만 근거로 답한다.
매수/매도 단정·수익 보장은 하지 않으며, 답변마다 자체 분석
출처를 인용·링크한다. 추론은 자체 호스팅 LLM(vLLM) + tool
그라운딩으로 구현한다.

## 3. 페르소나

### P1: 신중한 개인 투자자 (주 타겟)
- 5년+ 투자 경험
- 네이버 증권/유튜브의 정보 노이즈에 지침
- 1차 자료를 직접 확인하고 싶지만 시간이 없음
- 단정적 추천보다 사고 과정을 보고 싶어 함

### P2: 작성자 본인
- 글을 발행하기 위한 마찰을 최소화하고 싶음
- 자기 트랙 레코드를 자동으로 관리하고 싶음
- AI 보조는 받되, 글의 톤과 결정은 본인이 통제

## 4. MVP 범위

### 필수 (Must Have)
- 대시보드 (홈) — 라이브 시세, KPI, Hero 카드, 위젯 4종
- 분석 글 페이지 — 인라인 출처 배지, 신뢰도 사이드바
- 마크다운 기반 글 작성 워크플로 — frontmatter 스키마
- 신뢰도 점수 자동 계산
- Knowledge Graph 미니뷰 (대시보드 내 위젯)

### 추후 (Should Have)
- **지인 Agent MVP** — `/api/chat`, 자체 LLM + tool 그라운딩, 플로팅 위젯
- 가설 검증 보드 (전체 페이지)
- Knowledge Graph 전체 뷰
- 종목 상세 페이지 + Conviction Timeline
- AI 자동 출처 재검증 (주간 워크플로)

### 차후 (Could Have)
- 사용자 포트폴리오 vs 모델 포트폴리오 비교
- 구독/알림 시스템
- 다국어 (영문) 지원

## 5. 비기능 요구사항
- 빌드 시간 < 30초 (글 200편 기준)
- 라이트하우스 성능 점수 > 95
- 모바일 반응형 (320px ~)
- 다크 모드 지원
- 접근성 WCAG 2.1 AA
- 한국 사용자 우선 (KST, 원화, 한국어)

## 6. 비목표 (Non-Goals)
- 실시간 매매 시스템 아님 (정보 제공만)
- 종목 게시판/커뮤니티 기능 없음
- 백테스팅 도구 아님
- 일반 투자자 대상 교육 콘텐츠 아님 (전문가 톤)
